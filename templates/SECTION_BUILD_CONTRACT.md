### Source-diversity check

Consider where relevant:

- government/institutional records;
- political supporters;
- political opponents;
- people directly affected;
- marginalized populations;
- economic/data evidence;
- foreign observers;
- historians from materially different interpretive traditions.

This is not a quota. Include perspectives because they test or improve understanding.

## 8. Context pass

When relevant, establish:

- What did people know?
- What did they not know?
- What institutions and laws existed?
- What choices appeared realistically available?
- What economic incentives mattered?
- What cultural assumptions were common?
- What threats did actors perceive?
- Which words/concepts had different historical meanings?

Context explains behavior; it does not automatically excuse behavior.

## 9. Causation pass

For every major causal claim, check:

1. Did the proposed cause precede the outcome?
2. Is there evidence actors responded to it?
3. Is there a plausible mechanism?
4. Are competing explanations stronger?
5. Does the explanation survive relevant counterexamples?
6. What evidence would falsify/narrow it?
7. Is it a **cause**, **contributing factor**, **trigger**, **justification**, or **consequence**?

### Simple-story rule

Give the novice a usable mental model first. Add complexity only where that model stops being sufficient.

### Modern-connection rule

Do not claim “this caused modern X” without showing:

```text
historical event
→ later institution/movement/demographic/policy change
→ intermediate transformation(s)
→ surviving modern structure
```

If the bridge cannot be established, describe a similarity rather than causation.

### Myth / memory structure

When useful:

```text
COMMON VERSION
WHAT IT GETS RIGHT
WHAT IT LEAVES OUT
WHAT THE EVIDENCE SUPPORTS
WHY THE SIMPLER VERSION SURVIVED
```

Do not invent a straw-man myth.

## 11. Rung teaching pass

Check:

- **Orient:** Is the historical problem clear?
- **Prerequisite:** Did we provide knowledge the reader genuinely needs?
- **Diagnose:** What plausible misconception is being corrected?
- **Minimum help:** Are we avoiding unnecessary front-loading?
- **Reattempt:** Does later evidence make the reader revise the earlier simple model?
- **Verify:** Can the reader explain the core relationship?
- **Transfer:** Can the reader apply it to a fresh case?

## 13. Acceptance criteria

A section is DONE only when all applicable criteria pass:

- [ ] central question is answered as far as evidence permits;
- [ ] important factual claims have recoverable sources;
- [ ] material assumptions are not presented as facts;
- [ ] major causal claims include mechanisms, not chronology alone;
- [ ] important serious counterevidence has been investigated;
- [ ] disagreement/uncertainty remains visible where warranted;
- [ ] relevant actors are explained in historical context;
- [ ] modern connections have an evidenced causal bridge;
- [ ] the simple explanation works for a novice;
- [ ] necessary complexity is introduced without burying the basic model;
- [ ] transfer prompt tests the intended concept;
- [ ] required review passes.

## 14. Verification / review

### Review level

- `LOW` — straightforward factual/transition material: owner verifies.
- `MEDIUM` — important causal explanation/synthesis: reproduce evidence + independent review.
- `HIGH` — disputed/load-bearing interpretation: explicit evidence package + independent challenge/review.

MAPS_L reference:
[Checks and Balances](https://github.com/BigCatMellow/MAPS_Lean/blob/main/docs/CHECKS_AND_BALANCES.md)

### Reviewer receives

- section goal;
- central question;
- draft;
- major claims;
- claim-evidence matrix;
- known uncertainty;
- source package.

### Reviewer checks

- factual accuracy;
- source support;
- causation;
- historical context;
- material omission;
- counterevidence;
- interpretation presented as interpretation;
- modern causal bridge;
- novice comprehension / teaching.

### Verdict

`APPROVED | CHANGES_REQUESTED | BLOCKED — NEEDS RESEARCH`

## 15. Adversarial challenge when warranted

For a consequential interpretation that has escaped meaningful challenge:

1. state the conclusion so it could be wrong;
2. list assumptions required for it;
3. identify the weakest assumption;
4. build the strongest credible alternative;
5. state what evidence should exist if the alternative is true;
6. look for it;
7. record evidence that weakens the alternative too;
8. state reopening indicators.

Reference:
[MAPS_L Tenth Seat Review](https://github.com/BigCatMellow/MAPS_Lean/blob/main/playbook/TENTH_SEAT_REVIEW.md)

Boundary: use this as a History Book adversarial-review analogue; do not import the upstream PR-specific triggers as project rules.

## 16. Recovery

```text
local evidence failure     → RESEARCH / CORRECT
bad research decomposition → PLAN
broken historical frame    → THINK
unresolvable evidence      → DISPUTED / UNKNOWN
section no longer useful   → CUT / MERGE / RESTRUCTURE
```

Never protect prose from evidence.
