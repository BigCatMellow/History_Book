## Manuscript rule

A file belongs here only when it is written primarily for the reader.

Do not place:

- THINK/PLAN scratch work;
- claim-evidence matrices;
- review notes;
- internal status reasoning;
- source audits;

inside the manuscript unless the reader genuinely needs them.

The book may contain readable endnotes/source notes where useful, but the operational evidence package remains separate.
